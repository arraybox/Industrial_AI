# PJT_11-02

Flask로 간단한 로그인 화면을 구현하는 기초 웹 실습 폴더입니다. 하드코딩된 사용자 ID와 비밀번호를 검사하고, 로그인 성공 또는 실패 화면을 반환합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `app.py` | Flask 애플리케이션 본문 |
| `templates/login.html` | 로그인 입력 폼 템플릿 |

## 주요 기능

1. 홈 페이지
   - `/` 경로에서 로그인 페이지로 이동하는 링크를 표시합니다.

2. 로그인 페이지
   - `/login` 경로에서 GET/POST 요청을 모두 처리합니다.
   - GET 요청은 로그인 폼을 보여줍니다.
   - POST 요청은 입력된 `username`, `password`를 검사합니다.

3. 인증 로직
   - 기본 ID는 `admin`, 비밀번호는 `1234`입니다.
   - 일치하면 환영 메시지를 반환합니다.
   - 일치하지 않으면 `login.html`에 오류 메시지를 전달합니다.

## 실행 방법

```bash
pip install flask
python app.py
```

실행 후 브라우저에서 아래 주소로 접속합니다.

```text
http://127.0.0.1:5000
```

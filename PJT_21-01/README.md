# PJT_21-01

OpenCV의 이미지 표시, 마우스 이벤트, 키보드 입력 처리를 학습하는 폴더입니다. `chapter2.py`는 Lena 이미지 위에 사각형, 직선, 화살표를 직접 그릴 수 있는 간단한 드로잉 프로그램입니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `chapter2.py` | 이미지 로딩, 마우스 드래그, 키보드 모드 전환, 이미지 저장 실습 |
| `img/Lena.png` | 기본 입력 이미지 |
| `img/lena_draw.png` | 저장 예시 또는 실행 중 저장되는 결과 이미지 |

## 주요 기능

1. 이미지 로딩
   - 기본 경로는 `./img/Lena.png`입니다.
   - `--path` 인자로 다른 이미지를 지정할 수 있습니다.

2. 마우스 드로잉
   - 왼쪽 버튼을 누르고 드래그하면 현재 모드에 맞는 도형을 그립니다.
   - 드래그 중에는 임시 canvas에 미리보기가 표시됩니다.

3. 키보드 조작

| 키 | 동작 |
|---|---|
| `r` | 사각형 모드 |
| `l` | 직선 모드 |
| `a` | 화살표 직선 모드 |
| `w` | 현재 이미지를 `img/lena_draw.png`로 저장 |
| `c` | 원본 이미지로 초기화 |
| `ESC` | 종료 |

## 실행 방법

```bash
python chapter2.py
```

다른 이미지로 실행하려면 다음처럼 경로를 지정합니다.

```bash
python chapter2.py --path ./img/Lena.png
```

필요 라이브러리는 `opencv-python`입니다.

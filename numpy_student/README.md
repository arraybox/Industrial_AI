# numpy_student

NumPy 기본 문법을 실습하는 Jupyter Notebook 폴더입니다. `lec02_numpy_for_student_2025254015.ipynb` 한 파일로 구성되어 있으며, Python 리스트를 배열로 바꾸는 기초부터 배열 형태 변환, 연산, 결합, 복사 방식까지 순서대로 다룹니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `lec02_numpy_for_student_2025254015.ipynb` | NumPy 배열 생성과 기본 조작을 실습하는 노트북 |

## 주요 학습 내용

1. 배열 생성: `np.array`, `np.arange`, dtype 지정, 1차원/2차원 배열 생성
2. 배열 형태 변경: `reshape()`와 `-1`을 이용한 자동 차원 계산
3. 기본 연산: 배열 간 사칙연산, 제곱 연산, element-wise 곱과 행렬 곱 비교
4. 배열 결합: `np.hstack()`, `np.vstack()` 사용
5. 복사와 view: 슬라이싱 view, shallow copy, deep copy 차이 확인

## 실행 방법

```bash
jupyter notebook lec02_numpy_for_student_2025254015.ipynb
```

또는 VS Code에서 노트북 파일을 열어 셀 단위로 실행하면 됩니다.
